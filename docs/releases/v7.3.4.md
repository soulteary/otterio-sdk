# OtterIO SDK v7.3.4

## Runtime and dependencies

- Require Go 1.27.4 for the SDK and both example modules. This includes the Go standard-library fix for [GO-2026-6859](https://pkg.go.dev/vuln/GO-2026-6859).
- Consume `otterio-kits/crc64nvme v1.1.5` and `otterio-kits/md5-simd v1.2.3`; use `otterio-kits/sio v0.5.6` in the S3 example module.
- Update compression, YAML, INI, and `golang.org/x` runtime dependencies. Upgrade the pinned golangci-lint tool to v2.15.0 with its compatible dependency versions.
- Identify the client User-Agent and example SDK requirements as v7.3.4.

## Upstream fixes

The following fixes are adapted from MinIO Go SDK while retaining this fork's module path, package name, and serial compose implementation:

- Trim whitespace from error-response regions before falling back to the region header ([upstream change](https://github.com/minio/minio-go/commit/e2e7912cc02d236b37db3ad41891ead03257bce2)).
- Send the requested AssumeRole `DurationSeconds` value. Zero now omits the parameter so the server chooses its default; previously the SDK substituted 3600 seconds for values at or below 3600 ([upstream change](https://github.com/minio/minio-go/commit/a0742911cfe9bf1f08e317d475495b578140d4cd)).
- Trim whitespace from bucket location responses before interpreting the region ([upstream change](https://github.com/minio/minio-go/commit/21d2ec11d435a8026e40520d2d1a88ac32ccd6c0)).
- Serialize object-retention dates in UTC in PUT/copy headers and retention XML ([upstream change](https://github.com/minio/minio-go/commit/91dc4dd9f71f52ed8c1839a439d50827ff02499a)).
- Attempt cleanup of failed multipart uploads even after the caller cancels. Cleanup retains context values, has a one-minute timeout, and the operation returns its original failure. The same cleanup is applied to failed part copies in this fork's serial `ComposeObject` ([upstream change](https://github.com/minio/minio-go/commit/c68b12c3925dc91c8e75a2bff27bbea319237acd)).

The original source copyright and license notices are retained. This patch does not add upstream parallel GET/compose APIs or change the module path `github.com/soulteary/otterio-sdk/v7`.

## Validation

The local checks use Go 1.27.4 on Linux amd64. They cover module verification for all three modules, the uncached short race suite, the pinned linter, SDK and example builds, and compilation of the race-enabled functional test program. The regression cases include a mock HTTP server that cancels serial `ComposeObject` during part copy and verifies that cleanup still reaches the server.

Short tests skip the cases requiring a live S3 server. The release also requires the repository's Linux and Windows OtterIO core integration, RDMA build, and vulnerability checks to pass on the reviewed revision.
