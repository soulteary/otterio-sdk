# OtterIO SDK v7.3.2 release preparation

This document prepares v7.3.2; the tag and GitHub release are created after the release PR is merged and its required checks pass.

## Changes since v7.3.1

- Upgrade the Go requirement and CI toolchain from 1.27.1 to 1.27.2.
- Refresh runtime dependencies, including go-humanize 1.1.0, compress 1.20.1, msgp 1.6.5, and x/net 0.60.0, plus the pinned linter's dependency graph.
- Upgrade otterio-kits/crc64nvme from 1.1.2 to 1.1.3 and otterio-kits/md5-simd from 1.1.3 to 1.2.0. Upgrade the S3 example's otterio-kits/sio from 0.5.2 to 0.5.3.
- Set the SDK User-Agent version to v7.3.2 and align both example modules' SDK requirements with the intended release. Examples continue to use the local SDK through their existing replace directives.
- Include the documentation, API example, CI parallelization, legacy console fixture, and Windows assertion fixes already merged into main since v7.3.1.

The module path remains `github.com/soulteary/otterio-sdk/v7` and the Go package name remains `minio`. Consumers need Go 1.27.2 or newer. No exported SDK API is changed by this release preparation PR.

## Validation and publication

Run the checks in [CONTRIBUTING.md](../../CONTRIBUTING.md). The release PR records the completed local checks. Linux and Windows live-server tests, RDMA checks, and vulnerability scanning run in GitHub Actions; verify those results before publishing.

Local checks passed on Go 1.27.2 / macOS arm64: `go test -short -race ./...`, `go build ./...`, `make lint` (zero issues), `make examples`, functional-test program compilation with `-race`, and `go mod verify`. Live-server functional tests were not run locally.

Follow [MAINTAINERS.md](../../MAINTAINERS.md) to tag the reviewed, merged commit as `v7.3.2` and publish the release notes above. This repository has no automatic release publishing workflow. Do not publish from the preparation branch before merge.

After publication, consumers can select the release with:

```sh
go get github.com/soulteary/otterio-sdk/v7@v7.3.2
```
